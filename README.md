# HumScore（ハムスコア）

鼻歌を歌うだけでリアルタイムに五線譜へ変換し、MIDI / MusicXML / PNGで書き出せる
ハミング採譜Webアプリです。

## 動作対応OS・ブラウザ
- OS: Windows 10/11、macOS 14以降、iOS 17以降（Safari）、Android 13以降（Chrome）
- ブラウザ: Google Chrome / Microsoft Edge / Safari 最新版
- マイク必須。ブラウザの仕様上、HTTPS または localhost でのみ動作します。

## インストール手順・実行方法
インストール不要のWebアプリです。
1. 公開URLにブラウザでアクセス（ローカルの場合: このフォルダで
   `python -m http.server 8000` を実行し http://localhost:8000 を開く）
2. 「🎤 録音開始」を押し、マイクへのアクセスを「許可」
3. 鼻歌を歌うと、リアルタイムで五線譜が表示されます
4. 「■ 停止」後、MIDI / MusicXML / PNG をダウンロードできます
